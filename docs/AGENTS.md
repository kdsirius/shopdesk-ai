# 文档区规则

## 适用范围

本文件覆盖 `docs/` 及其子目录，并与仓库根目录 `AGENTS.md` 叠加生效。与文档格式有关的局部规则以本文件为准。

## 局部差异

- `study/` 只保存 16 节学习文档，按 `day01` 至 `day16` 对应参考视频天数。
- 学习文档只写业务/原理/流程、用户手敲代码和真实验证；汇报记录、重复环境记录和无关扩展不写入。
- 可落盘代码块正上方必须紧邻一行 `**文件**：`，路径相对仓库根目录；不要把 `reference/` 路径作为写入目标。
- `memory/learning-progress.md` 是唯一进度源；其他记忆文件记录事实、方法和欠账，不重复维护章节状态。
- `study/images/` 只存教程需要的图片；Mermaid 能表达时优先用 Mermaid，并使用相对路径引用图片。
- `superpowers/` 保存设计和执行计划，不写学习代码。

## 本区域的验证方式

- 章节文档检查标题骨架、文件标记、路径和状态值。
- 代码片段必须在 `workspace/` 的隔离副本中抽取和运行；未运行命令标为“未验证”。
- 章节验收通过后才更新进度、验收记忆和下一节提示词。沿用根 `AGENTS.md` 的验证状态约定。
