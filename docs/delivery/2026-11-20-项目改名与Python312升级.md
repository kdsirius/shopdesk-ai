# 项目改名、配置键切换与 Python 3.12 升级

## 改了什么

- Python 发行名、wheel 名和 CLI 改为 `shopdesk-ai`（wheel 文件名按规范写作 `shopdesk_ai`）。应用标题统一为 ShopDesk AI（商答台）；导入包仍是 `app`，Web 启动路径仍是 `app.api.main:app`。
- 最低 Python 版本改为 `>=3.12`，项目默认解释器使用 3.12 系列。依赖约束不变，uv 更新锁文件以反映发行名和 Python 支持边界。
- 删除配置键开头的 `SHOPKEEPER_BRAIN_`，保留子系统前缀、原值格式和配置优先级。旧键不读取。用户本地 `.env` 由用户迁移，仓库目录、HTTP 路由、浏览器会话键和业务数据保持不变。

## 配置迁移对照

旧键是下表每个新键前面加 `SHOPKEEPER_BRAIN_`。例如 `SHOPKEEPER_BRAIN_LLM_API_KEY` 改成 `LLM_API_KEY`。仅修改键名，不改等号后的值、不直接用模板覆盖原 `.env`；如果 PyCharm 启动配置、终端或部署环境也设置了旧键，一并改名。现有进程变量继续优先于 `.env`，同名变量有冲突时先处理启动环境。

| 配置 | 新键 |
| --- | --- |
| MinerU | `MINERU_BASE_URL`、`MINERU_API_TOKEN` |
| 视觉模型 | `VL_BASE_URL`、`VL_API_KEY`、`VL_MODEL`、`VL_TEMPERATURE` |
| 文本模型 | `LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`、`LLM_TEMPERATURE` |
| 图片限流 | `IMAGE_MAX_REQUESTS`、`IMAGE_WINDOW_SECONDS` |
| MinIO | `MINIO_ENDPOINT`、`MINIO_ACCESS_KEY`、`MINIO_SECRET_KEY`、`MINIO_BUCKET`、`MINIO_IMAGE_PREFIX`、`MINIO_SECURE` |
| BGE-M3 | `BGE_M3_PATH`、`BGE_DEVICE`、`BGE_FP16` |
| Milvus | `MILVUS_URI`、`MILVUS_ITEM_NAME_COLLECTION`、`MILVUS_CHUNK_COLLECTION` |
| MongoDB | `MONGO_URI`、`MONGO_DB_NAME` |
| Tavily | `TAVILY_MCP_URL`、`TAVILY_API_KEY` |
| 重排 | `RERANK_MODEL`、`RERANK_INSTRUCT`、`RERANK_API_KEY` |
