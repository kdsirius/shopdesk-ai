# 雾蓝演示页实施计划

> 按已确认的风格和范围由当前会话执行，不改后端接口，不提交 Git。

**目标：** 查询页用淡雾蓝、单列对话和底部输入框呈现真实问答；首页和导入页只统一界面风格。

**实现：** 保留三页同源 HTML、CSS、JavaScript 与现有 API。只在前端组装问题、流式回答、配图和历史；完成后以文本节点和 DOM 元素显示正文基础格式，不把模型内容拼成 HTML。首页保留健康检查，导入页保留原表单和状态轮询。

- [x] 在实验区启动只读读取真实 HTML 的 HTTP 夹具。先用浏览器核对旧查询页无法把答复和历史放到同一个对话流。
- [x] 修改查询页：居中对话流、页底输入、当前进度和答复、每条答复的配图、基础 Markdown 排版。复验流式内容、失败提示、刷新历史和窄屏。
- [x] 修改首页和导入页：沿用品牌导航、颜色和按钮样式。验证首页健康检查和导入页选择文件、提交、轮询行为。
- [x] 用隔离 MongoDB 与已有 RS-12 实验 Milvus 集合启动实际应用。复验问答、原手册配图、历史，并拍摄真实答复页面。替换 README 引用的旧图，补交付文档，核对工作区。
